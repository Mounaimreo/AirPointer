# AirPointer v1.4.0

مؤشر هوائي كامل الشاشة فوق التطبيقات.

- تحريك المؤشر بالإصبع من مسافة 5–10 سم.
- قرصة الإبهام والسبابة للنقر.
- قرصتان للنقر المزدوج.
- القرصة المستمرة للسحب والضغطة المطولة.
- الكف المفتوح للتمرير والرجوع والتطبيقات الحديثة.

يتطلب منح إذن العرض فوق التطبيقات وتفعيل خدمة سهولة الاستخدام لتنفيذ النقرات والتنقل.
