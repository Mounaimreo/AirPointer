# AirPointer v1.4.0

مؤشر كمبيوتر يتحرك فوق الشاشة بالكامل ويتبع السبابة من مسافة 5–10 سم.

## الإيماءات

- السبابة للتحريك.
- قرصة الإبهام والسبابة للنقر والنقر المزدوج.
- إمساك القرصة للسحب والضغطة المطولة.
- الكف المفتوح لأعلى/أسفل للتمرير.
- حركة الكف أفقيًا للرجوع أو التطبيقات الحديثة.

التنزيل المباشر:
https://github.com/Mounaimreo/AirPointer/releases/download/airpointer-v1.4.0/AirPointer-v1.4.0.apk?download=1

لا يطلب التطبيق إذن الظهور فوق التطبيقات. يُعرض المؤشر كنافذة Accessibility Overlay بعد تفعيل خدمة AirPointer يدويًا من إعدادات سهولة الاستخدام. لا تقرأ الخدمة محتوى الشاشة، وتنفذ فقط النقرات التي يطلبها المستخدم بإشارة اليد.

على Android 13 أو أحدث، قد تحتاج إلى السماح بالإعدادات المقيّدة من صفحة معلومات التطبيق قبل تفعيل خدمة إمكانية الوصول. هذا إجراء يقرره النظام ولا يتجاوزه التطبيق.
